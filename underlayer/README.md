# AWAKEN / UNDERLAYER

Standalone prototype only. It does not modify the original JE layout or existing pages.

## Idea

JE is the printed/public surface. NETWORK is the computational substrate underneath it. The prototype renders both at once and lets the visitor scan through the newspaper to reveal the system map below, then fully breach into that underlayer.

This is not intended to replace JE or NETWORK. It is a third experience built from their strongest ideas.

## Interaction

- Select **SCAN PAGE** and move the pointer to reveal the NETWORK beneath the paper.
- Press **S** to arm/disarm the scanner.
- Press **Enter** or **Space** to breach into the underlayer.
- Press **Escape** or use **RETURN TO PAPER** to go back.
- Touch devices enter the underlayer directly from **SCAN PAGE**.

## Design rules

- No generic SaaS cards, glass panels, gradient UI, rounded dashboard language, or decorative fake-futurism.
- The print surface uses hard editorial hierarchy, physical-paper cues, asymmetry, rules, type and existing AWAKEN imagery.
- The underlayer is a restrained system topology, not a neon HUD.
- Existing JE routes remain useful destinations rather than being copied into the prototype.
- NETWORK stays a real destination and deeper system.
- The two layers should feel like different manifestations of one institution.
